# Ahsan Tufail — Digital Architect Portfolio

Personal portfolio website for Ahsan Tufail — specialist in Programming, Cloud Infrastructure, AI/ML Systems, and Architectural Automation.

**Live site:** [ahsantufail.dev](https://ahsantufail.dev)

## Tech Stack

- **Framework:** React 18 + TypeScript
- **Build tool:** Vite
- **Styling:** Tailwind CSS (Obsidian/Cyber-Blue dark theme)
- **UI components:** shadcn/ui + Radix UI
- **Animations:** Framer Motion
- **Smooth scrolling:** Lenis
- **Flow diagrams:** React Flow (`@xyflow/react`)
- **Fonts:** Instrument Serif (display) · JetBrains Mono (body/mono)

## Local Development

```sh
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
